# Art. 69 Abrogations
1 Le présent règlement abroge les actes législatifs suivants :
a. Règlement du 20 août 2003 instituant les règles pour l'octroi par l'Etat d'une aide financière aux manifestations sportives (RAFMS ; RSV 415.01.3) ;
b. Règlement du 20 mai 1977 sur Jeunesse+Sport (RJS ; RSV 415.11.1) ;
c. Règlement du 20 mai 1977 sur l'éducation physique dans les écoles (REPE ; RSV 415.01.1).
