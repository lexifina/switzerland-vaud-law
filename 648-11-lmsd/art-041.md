# Art. 41 Inventaire
1 Le préposé établit un inventaire fiscal, sauf s'il s'agit d'une personne notoirement sans ressource ou si l'actif net est manifestement absorbé par les dégrèvement prévus à l'article 31.
2 Lorsque la loi civile prévoit un inventaire civil, celui-ci sert de base à l'établissement de l'inventaire fiscal.
3 Le préposé aux impôts peut assister aux opérations de l'inventaire civil.
4 Le préposé aux impôts peut commettre un expert, avec mission de dresser l'inventaire. Les règles du code de procédure civile du canton de Vaud sur l'expertise s'appliquent par analogie.
5 La forme de l'inventaire est régie par les règles du code de procédure civile.
