# Art. 14 Durée de l'engagement
1 Le premier engagement d'un assistant est conclu pour un an. Les trois premiers mois de travail sont considérés comme temps d'essai.
2 Le contrat peut être reconduit pour une période de deux ans, renouvelable une fois pour la même période. Dans ce cas, il n'y a pas de temps d'essai.
3 Les contrats sont conclus de manière consécutive.
