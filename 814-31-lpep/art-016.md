# Art. 16 Autorisations du département
1 Le département détermine le mode de traitement et d'évacuation des eaux usées.
2 Dans les cas prévus par la législation fédérale, le département est également compétent pour autoriser:
a. le déversement d'eaux usées épurées dans les eaux publiques ou privées;
b. le déversement d'eaux usées dans les fosses sans écoulement.
3 Le département est également compétent pour autoriser le déversement d'eaux usées, prétraitées ou non, provenant d'installations artisanales ou industrielles dans le réseau des canalisations publiques ou dans les eaux du domaine public. L'article 50 est applicable par analogie.
4 Le département statue sur les exceptions à l'interdiction d'introduire des eaux usées dans le sous-sol.
