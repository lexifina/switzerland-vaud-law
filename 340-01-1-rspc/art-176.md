# Art. 176 Autorisations de sortie
1 L'autorité compétente peut octroyer des congés selon le barème suivant :
a. 1er mois : maximum 60 heures ;
b. 2ème mois : maximum 72 heures ;
c. 3ème mois : maximum 84 heures ;
d. 4ème mois : maximum 96 heures ;
e. 5ème mois : maximum 108 heures ;
f. 6ème mois : maximum 132 heures
g. dès le 7ème fois : maximum 156 heures.
2 La direction de l'établissement peut, avec l'accord de l'autorité dont la personne condamnée dépend, accorder des congés spéciaux.
3 Cependant, dans tous les cas, la durée maximale d'un congé ininterrompu est de 72 heures.
