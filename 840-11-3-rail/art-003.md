# Art. 3 Modèle cantonal
1 Le Conseil d'Etat détermine, par arrêté, le modèle cantonal pour l'octroi de l'aide individuelle au logement qui comprend :
a. les types de ménages ;
b. les limites minimale et maximale du revenu déterminant par type de ménage ;
c. le taux d'effort supportable par tranches de revenus ;
d. le loyer maximum par catégorie de logement.
